# D008 - Current-tree phone privacy remediation

**Date:** 2026-07-31
**Owner:** Bongo Seakhoa
**Implementer:** Codex
**Status:** Adopted for the current release

## Finding

The replacement Static View and browser-generated documents do not publish a
phone number. A final pre-commit audit nevertheless found the retired value in
legacy tracked JSON, four legacy HTML document pages, four obsolete legacy PDFs,
one test fixture and an independent audit quotation.

## Action

- Clear the legacy JSON field.
- Remove the value from all legacy HTML.
- Redact the value from the audit record.
- Use an explicitly fictional value in the rejection test.
- Remove the four obsolete legacy PDFs from the current tree. The replacement
  PDFs are generated by the JavaScript and Chromium production pipeline.
- Retain automated public-output and PDF text checks that reject a public phone.

## History boundary

The retired value may remain reachable in historical commits that existed
before this remediation. Rewriting public Git history and force-pushing rewritten
references would disrupt clones, tags and existing commit links. That operation
requires explicit owner approval and is not inferred from the website release
instruction.

The current repository tip and production artifact must remain clean even while
that separate decision is pending.
